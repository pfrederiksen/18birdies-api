# Code Of Conduct

Everyone participating in this project's issues, discussions, and pull requests
should be able to contribute without harassment or intimidation. Be respectful,
welcome questions, and explain disagreements with specific reasons. Critique
the work without attacking the person.

Harassment, threats, discriminatory abuse, unwanted sexual attention, and
sharing another person's private information are not acceptable. Respect
boundaries and requests to stop. Protect contributors' privacy as carefully as
the golf data this project processes.

Maintainers may remove inappropriate content, limit participation, or block
accounts when needed to protect the community. Responses should reflect the
behavior and its impact, with room to correct an honest mistake.

To address misconduct, use GitHub's existing report-abuse and blocking tools,
or an already-established private channel with a maintainer. Do not publish
incident details or personal information in project issues. Never attach real
golf exports, account data, credentials, or private logs to an issue or report.

Security vulnerabilities belong in the repository's private security reporting
flow described in [SECURITY.md](SECURITY.md), not in public issues.
