# Banner Artwork

`18birdies-banner.jpg` is original AI-generated artwork created for this project
with OpenAI's built-in `image_gen` tool. It depicts an imaginary golf hole, not
a real user's round, location or shot data. No official 18Birdies branding is used.
The generated bitmap was converted to JPEG for a smaller download, with embedded
metadata removed. The illustration itself was not changed.

Generation prompt:

> Create a polished wide landscape README banner bitmap for an independent
> open-source local golf-data analysis library. Clean editorial illustration,
> a single golf hole seen from an elevated three-quarter angle, crisp fairway
> and putting green, a white dimpled golf ball in foreground, tasteful dotted
> shot trajectory linking small measured positions across the course, subtle
> scorecard grid and a few minimal chart lines integrated into the composition.
> Spacious horizontal composition, fresh grass green contrasted with white,
> charcoal, and a small coral-red flag accent. Sophisticated technical sports
> aesthetic, sharp clear shapes with tactile printed-paper texture, not a
> dashboard screenshot. No people, no personal data, no logos or trademarks,
> no real locations, no proprietary app UI, no text or numbers. Should
> communicate private local golf analysis and tracked shots. Wide 2:1
> composition suitable for a GitHub README header.
